## What I would fix first if there were more time

**Apply the opaque-name control catalog to `agent_raw`.** `docs/DECISIONS.md` specifies it, and
`uv run datahub-emit --baseline` builds and emits it, but the agent modes query the real warehouse
with readable names, so the intended handicap was never wired in. This is very likely why
descriptive metadata showed no measurable effect: `agent_raw` reads `income_tax_rate` and
`road_maintenance_budget` straight from `information_schema` and infers most of what a description
would have told it.

Second: more seeds. `agent_datahub_live`'s margin is far outside the observed 0.02 run-to-run
variance. `agent_datahub`'s is not comfortably so — across four paired runs that gap ran +0.045,
+0.043, **−0.040**, +0.053.

Third: the `human` mode. The lever panel and scene work and are verified against the live server,
but the upstream Analytics Agent is not wired in, so there is no human baseline.
