# Viewer

Canvas tile map and the eight-lever panel. Nothing else.

**The hard constraint.** No charts, no counters, no trend lines, no alerts, no coloured warning
states. Any instrumentation here defeats the premise of the entry — the whole point is that the
player cannot read the city's condition off the screen and must ask the agent instead. This is
called out in both AGENTS.md and docs/FEATURES.md.

Showing the city is fine. Showing *statistics about* the city is not. A tile that looks visibly
run-down is the city; a number next to it is instrumentation.

Lever names, ranges, and defaults come from `blindcity.levers` — do not restate them here.

Deliberately left unbuilt: no framework has been chosen, and viewer polish is second on the cut line
in TASKS.md. Plan: Day 7.
